# Batasa Architecture

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Next.js API Routes
- Supabase

### Database
- PostgreSQL
- Row Level Security (RLS)

### Authentication
- Supabase Auth

### Deployment
- Railway
- Vercel

### Integrations
- Channel Managers
- WhatsApp
- Email
- Payment Gateway

---

## Engineering Principles

- Modify existing code before creating new files.
- Keep the architecture simple.
- Never duplicate business logic.
- Business rules belong in services.
- Database changes require approval.
- All critical operations must be transactional.
- Security by default.
- Performance before premature optimization.
