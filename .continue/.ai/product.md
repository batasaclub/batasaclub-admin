# Batasa Product

## Vision

Batasa is India's Hospitality Growth OS.

The goal is to help independent hotels increase profitable direct business, reduce OTA dependency, and simplify operations.

Membership is one capability—not the product.

---

## Core Modules

- Membership
- Direct Booking
- Guest CRM
- Revenue Dashboard
- Campaign Manager
- Corporate Portal
- Hotel Operations
- Analytics
- Channel Manager Integration
- Settlement Engine

## Product Principles

- Hotel First
- ROI First
- Simple UX
- Secure by Design
- Mobile First
- AI Assisted
- API First

---

## Non-Negotiables

- No duplicate functionality
- Keep workflows under 3 clicks where possible
- Every feature must create measurable business value
- Prefer configuration over custom code
- Production-ready before release

---

## Mission

Increase hotel profitability by helping hotels:

- Increase direct bookings
- Reduce OTA dependency
- Increase repeat guests
- Improve guest lifetime value
- Simplify hotel operations
- Make better revenue decisions
